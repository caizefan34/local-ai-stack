🏋️ Fine-tuning

LoRA Fine-tuning Pipeline

From conversation data collection to a fully trained Ollama model.

1

📥 Collect Data

Import conversations from Codex, CC Switch, or your own Q&A logs.

2

🧹 Prepare & Format

Convert to training-ready format. Filter, deduplicate, and split into train/val sets.

3

🏋️ Train (QLoRA)

4-bit QLoRA with paged_adamw_8bit. Fits in 8 GB VRAM for Qwen3-8B.

4

📤 Export to Ollama

Merge LoRA weights, create a Modelfile, and deploy your custom model.

# One-command pipeline
cd lora-finetune

# Step 1: Collect data
python scripts/collect_data.py

# Step 2: Train (QLoRA, ~4.5 GB VRAM)
python scripts/train.py

# Step 3: Export & deploy
python scripts/merge_and_export.py
ollama create my-finetuned-model -f Modelfile
